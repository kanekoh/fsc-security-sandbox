# samples/

Optional sample manifests for demos (also deployed via `helm/components/sample-apps`).

| Planned / used | Purpose |
|---|---|
| Vulnerable / older UBI image | RHACS vulnerability views |
| Privileged / `:latest` style workload | RHACS policy demos |
| Unsigned image | RHTAS verification demos |
| Small SBOM file | RHTPA demos |

Use public images only. Do not add credentials.
